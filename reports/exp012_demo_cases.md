# EXP-012 발표용 실제 결손 데모 사례 (후보 압축)

> **상태:** 후보 압축 완료 · 한문 판독 최종 선택은 팀 검토 필요  
> **모델:** `exp012_sillokbert_gpu_best_valid_loss` (EXP-012 best)  
> **출처 풀:** `reports/expert_panel/expert_review_panel.csv`의 `real_defect` 25건  
> （1차 풀은 `outputs/predictions/exp012_real_defect_predictions.csv` 3,704건에서  
> `src/eval/select_expert_panel.py`가 분산 샘플링한 결과. 본 환경에는 전수 CSV가 없어 패널을 재사용.）

## 중요 고지

- 실제 결손 `□`에는 **정답(gold)이 없다.** Exact@k·“맞았다” 서술을 쓰지 않는다.
- `top*_score`는 vocab softmax의 **후보 간 상대 선호도**일 뿐, 신뢰 확률·교정 확률이 아니다.
- 아래 7건은 발표·정성 검토용 **후보**이며, 한문 판독 지식이 필요한 최종 채택은 팀 검수를 거친다.

## 선별 기준

| 기준 | 적용 |
|------|------|
| 점수 혼합 | `top1_score` high / mid / low 버킷을 섞음 (패널 내 범위 ≈ 0.015–0.906) |
| 비문당 1건 | `inscription_id` 중복 없음 |
| 노이즈 배제 | HTML/`imgsrc`/CSS 조각, 각주 마크업(`1)` 등)이 문맥에 섞인 행 제외 |
| 문맥 길이 | 마스크 좌우에 읽을 만한 한자 문맥이 남는 사례 우선 (전면 `□`만인 창 배제) |
| 시대 분산 | 패널 real_defect 25건이 **고구려 24 + 가야 1**로 편향(가야 1건은 HTML 노이즈로 제외). 시대 분산은 전수 3,704 재선별 시에만 개선 가능 |
| 해설 가능성 | 간지·관직호·불상 발원문 등 발표에서 문맥 설명이 쉬운 사례 우선 |

### 1. `real_000280` — 금동계미명삼존불입상 (high)

- **inscription_id:** `insc_nrich_002559`
- **마스크 문맥:** `癸未年十一月一日」宝華爲亡父趙[MASK]人造」`
- **원문 결손 위치:** `…亡父趙□人造」` (`defect_position=15`)
- **top-5:** 夫 (0.906) · 淑 (0.012) · 氏 (0.011) · 庶 (0.005) · 主 (0.004)
- **해설:** 상대 선호도가 top1에 크게 쏠린 사례. “문맥상 인칭·호칭 후보를 제시했다” 수준으로만 설명. 정답 단정 금지.

### 2. `real_000275` — 태자명와당 (high)

- **inscription_id:** `insc_nrich_002546`
- **마스크 문맥:** `泰」歲[MASK]戌年造瓦所記」`
- **원문 결손 위치:** `歲□戌年` (`defect_position=3`)
- **top-5:** 戊 (0.395) · 壬 (0.174) · 丙 (0.154) · 庚 (0.153) · 甲 (0.108)
- **해설:** top-10이 천간으로만 구성. 모델이 간지 연호 슬롯을 학습한 정성 사례로 쓰기 좋음. 역시 “정답”이 아니라 후보군 품질 이야기.

### 3. `real_000254` — 위관구검기공비 (high)

- **inscription_id:** `insc_nrich_007192`
